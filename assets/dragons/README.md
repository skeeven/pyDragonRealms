# Dragon Realms Artwork Assets (v0.19)

Place WebP illustrations under the following paths:

- `assets/dragons/stone/granitehide.webp` — dragon_stone_1
- `assets/dragons/storm/stormspire.webp` — dragon_storm_8
- `assets/dragons/grove/mossback.webp` — dragon_grove_1

The application automatically uses a portrait if its file exists and
falls back to the original generated SVG otherwise. File sizes are
limited to 2 MB per image.

To install the separate v0.19 artwork ZIP, extract its `assets/`
folder into the repository root. No Python dependencies are added.

Note: Granitehide is an original generated portrait, Stormspire is
cropped from an original generated UI concept image, and Mossback is a
forest-toned painted adaptation of the Granitehide portrait. The latter
is temporary showcase art, not an independent final character portrait.
